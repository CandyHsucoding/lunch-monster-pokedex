# 午餐小怪獸圖鑑

一款可直接用瀏覽器打開的均衡餐盤答題收集遊戲。學生答對一題，就解鎖一隻原創午餐小怪獸。

## 適合對象

國中學生、國小高年級學生，以及校園午餐營養教育課程。

## 學習目標

- 認識均衡餐盤中的全榖雜糧、豆魚蛋肉、蔬菜、水果與乳品類。
- 練習判讀午餐菜單中的食物類別。
- 了解日常減鈉與多樣化飲食的基本觀念。

## 玩法

1. 閱讀每一題午餐情境。
2. 選出最符合均衡餐盤或午餐判讀的答案。
3. 答對即可解鎖一隻午餐小怪獸。
4. 完成 8 題後，查看收集圖鑑。

## 使用方式

打開 `index.html` 即可遊玩。

## GitHub Pages 部署

這是純 HTML、CSS、JavaScript 靜態網頁。上傳到 GitHub 後，可在 repository 的 `Settings` → `Pages` 將來源設為 `main` branch / root，即可發布成網頁。

## 修改題目

題目在 `script.js` 的 `questions` 陣列中，可以直接改成學校午餐菜單或營養教育題目。

## 修改小怪獸

小怪獸在 `script.js` 的 `monsters` 陣列中，可以修改名稱、類型、說明與顏色。

`lunch-monsters.png` 是用 imagegen 生成的原創午餐小怪獸角色表。`assets/monster-01.png` 到 `assets/monster-08.png` 是從角色表裁出的正方形圖片，圖鑑卡片會用這些圖片等比例顯示角色。

## 素材說明

小怪獸圖片為本專案生成的原創角色，不使用既有動漫或遊戲角色。
